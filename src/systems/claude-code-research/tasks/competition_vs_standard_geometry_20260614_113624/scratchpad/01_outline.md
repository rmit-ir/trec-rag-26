# Outline: Competition vs. Standard High School Geometry

## Audience
- Knows standard US high-school geometry (two-column proofs, congruence, similarity,
  Pythagoras, basic circle facts, intro trig/SOH-CAH-TOA, area formulas).
- No competition-math experience.

## Goal
Contrast the *culture, goals, and toolkit* of competition Euclidean geometry (AMC/AIME/Olympiad)
with the standard curriculum. Show concrete theorems + techniques that competition students use
but that classrooms skip. Must include worked examples.

## Structure
1. Hook + the core difference (verification vs. discovery; speed vs. proof)
2. What standard class trains you to do (the baseline)
3. The competition mindset shift: angle chasing, auxiliary constructions, configurations
4. The "missing" theorems toolbox:
   - Power of a Point  (worked example)
   - Directed angles + angle chasing (worked example / Fact 5 incenter-excenter lemma)
   - Mass point geometry / Ceva / Menelaus  (worked example)
   - Ptolemy's Theorem  (worked example)
   - Extended Law of Sines / circumradius R = abc/4K
   - Spiral similarity, homothety, radical axes, inversion (survey, lighter)
5. The "bash" techniques: coordinates, trig, complex numbers, barycentric
6. The three contest tiers (AMC -> AIME -> Olympiad) and how geometry differs at each
7. How to start learning / takeaways

## Worked examples to include (must be correct)
- POP: two secants / chord-chord, plus a tangent example.
- Mass points: cevian ratio problem.
- Ptolemy: compute a length in a cyclic quadrilateral / regular pentagon diagonal.
- Angle chase: inscribed-angle based result.

## Tone
Friendly, concrete, encouraging. Use diagrams-in-words since this is markdown text.
